C-ROSS Phase II · 监管规则第 6 号 · Pillar I

第6号：再保险风险 —— 交易对手违约 + 负债波动

Reinsurance Risk
Pillar I · 第一支柱 再保资产违约 + 负债波动 信用评级差异化因子 加法聚合

再保险风险的定义 Definition Reinsurance Risk

再保险风险是指保险公司因再保险安排而面临的交易对手违约风险和再保险信用风险。当保险公司将部分风险分出给再保险人时，再保险人的偿付能力直接影响保险公司再保安排的有效性——若再保险人违约，保险公司将独自承担全部风险。

再保险风险最低资本基本公式 MC再保 = MC再保资产违约 + MC再保负债波动
MC_reinsurance = MC_default + MC_volatility

两个组成部分采用加法聚合，因为资产违约风险和负债波动风险
在性质上不同，不存在显著统计相关性
"违约 + 波动"双维度

再保险风险的两个维度覆盖了再保险安排的全周期风险：① 再保险资产违约风险——再保险人未能履行赔付义务，导致应收分保账款损失；② 再保险负债波动风险——分出业务对负债评估的影响存在不确定性。两者采用加法聚合，因为资产端和负债端的再保险风险性质不同，统计上不显著相关。

两大组成部分 Two Components Default & Volatility

1. 再保险资产违约风险 Reinsurance Asset Default Risk

再保险资产违约风险反映再保险人未能履行赔付义务的风险。保险公司分出业务后，应收分保账款成为资产，再保险人的信用质量直接影响该资产的可回收性。

再保险资产违约风险最低资本公式 MC再保资产违约 = 应收分保账款 × 再保险人信用风险因子
信用风险因子取决于再保险人的信用评级
评级越高 → 因子越低 → 资本要求越低
评级越低 → 因子越高 → 资本要求越高

2. 再保险负债波动风险 Reinsurance Liability Volatility Risk

再保险负债波动风险反映分出业务对负债评估的不确定性影响。分出业务后的净负债评估涉及再保险摊回的假设，这些假设的偏差会导致负债波动。

再保险负债波动风险最低资本公式 MC再保负债波动 = 分出业务负债 × 波动风险因子
波动风险因子通常 0.5%~2%
因子取决于分出业务类型和再保险安排结构
为何采用加法而非矩阵聚合

再保险风险的两个组成部分——资产违约风险和负债波动风险——在性质上完全不同：前者是再保险人信用风险（交易对手层面），后者是负债评估的不确定性（精算假设层面）。两者之间不存在显著的统计相关性，因此采用直接加法而非相关系数矩阵聚合。这与非寿险巨灾风险的加法处理逻辑类似。

再保险风险在保险风险中的位置 Position in Insurance Risk Link to Rules 4, 5 & 2

再保险风险是保险风险最低资本（MC保险）的第三个组成部分，与寿险保险风险（第5号）和非寿险保险风险（第4号）并列。

保险风险最低资本构成 MC保险 = MC寿险（第5号） + MC非寿险（第4号） + MC再保（第6号）
三者采用加法聚合

MC可资本化 = √(MC保险² + MC市场² + MC信用² + 交叉项)（第2号）
MC = MC可资本化 × (1 + k)（第2号）
再保险风险的特殊性

再保险风险与寿险/非寿险保险风险的性质不同——寿险和非寿险保险风险反映的是直接承保业务的风险偏差，而再保险风险反映的是再保险安排引入的额外风险。再保险本身是一种风险转移工具，但在转移风险的同时引入了交易对手（再保险人）的信用风险。因此再保险风险是"风险管理的风险"。

与第7号规则的衔接 Link to Rule 7 Look-Through for Reinsurance

再保险风险的计量还需考虑再保险合同的穿透计量（第7号规则）。对于复杂的再保险安排（如转分保、再保险合同中的嵌套结构），需要穿透至最终的风险承担方，按其信用质量计量风险。

"应穿尽穿"原则对再保险的影响

二期第7号规则要求对再保险安排实施"应穿尽穿"——对于转分保（再保险人将业务再次分出给其他再保险人），需穿透至最终再保险人，按最终再保险人的信用评级计量违约风险。无法穿透的再保险安排适用惩罚性风险因子，倒逼保险公司选择可穿透的再保险结构。

再保险资产违约风险 Reinsurance Asset Default Risk Counterparty Credit Risk

再保险资产违约风险最低资本以应收分保账款为基础，乘以再保险人信用风险因子。因子取决于再保险人的信用评级。

再保险资产违约风险最低资本公式 MC再保资产违约 = 应收分保账款 × 再保险人信用风险因子
应收分保账款 = 再保险人欠分出人的分保赔款和分保费用
若有多家再保险人，按各家信用评级分别计算后加总

再保险人信用风险因子表 Counterparty Credit Factors

再保险人信用评级 信用风险因子 说明
AAA级 0.5% 最高信用质量，违约概率极低
AA级 1.0% 高信用质量，违约概率很低
A级 2.0% 中高信用质量，违约概率较低
BBB级 4.0% 中等信用质量，违约概率中等
BB级 8.0% 低信用质量，违约概率较高
未评级 10.0% 无外部评级，适用惩罚性因子
未评级再保险人的惩罚性因子

未评级再保险人适用 10% 的惩罚性信用风险因子——是AAA级再保险人的 20倍。这是二期的重要改革，旨在倒逼保险公司选择有外部评级的再保险人，或要求未评级再保险人提供担保品（信用证、现金担保等）以降低资本要求。

因子差异化的原理

信用风险因子随评级下降呈倍数递增：AAA→AA翻倍（0.5%→1.0%），AA→A翻倍（1.0%→2.0%），A→BBB翻倍（2.0%→4.0%），BBB→BB翻倍（4.0%→8.0%）。这种倍数递增反映了低评级再保险人违约概率的非线性上升——评级每下降一级，违约概率大约翻倍。

再保险负债波动风险 Reinsurance Liability Volatility Risk Reserve Volatility

再保险负债波动风险最低资本以分出业务负债为基础，乘以波动风险因子。

再保险负债波动风险最低资本公式 MC再保负债波动 = 分出业务负债 × 波动风险因子
分出业务负债 = 分出业务对应的准备金
波动风险因子约 0.5%~2%
因子取决于分出业务类型（比例/非比例）和再保险结构
负债波动风险的来源

分出业务负债的波动来源于：① 再保险摊回的不确定性——再保险人按约定比例摊回赔款，但摊回金额的精算估计存在偏差；② 再保险合同条款的复杂性——特别是非比例再保险（如超赔合约）中，摊回金额的计算依赖复杂参数，不确定性更大；③ 再保险人偿付能力变化——再保险人偿付能力恶化可能导致摊回预期下调。

比例再保险（成数合约） 0.5% 结构简单，波动性低
比例再保险（溢额合约） 0.8% 结构相对简单
非比例再保险（超赔合约） 1.5% 结构复杂，波动性中等
非比例再保险（巨灾超赔） 2.0% 结构最复杂，波动性最高

再保险合同的穿透计量 Look-Through for Reinsurance Link to Rule No.7

再保险风险的计量还需考虑再保险合同的穿透计量（第7号规则）。对于复杂的再保险安排，需要穿透至最终的风险承担方。

穿透计量的核心要求

二期对再保险安排实施"应穿尽穿"原则，核心要求包括：

  • 转分保穿透：再保险人将业务转分给其他再保险人时，需穿透至最终再保险人，按最终再保险人的信用评级计量违约风险
  • 再保险合同嵌套：对于包含多层结构的再保险合同，需穿透至各层风险承担方分别计量
  • 无法穿透的惩罚：无法穿透的再保险安排适用惩罚性风险因子（远高于正常水平），倒逼保险公司选择可穿透的再保险结构
  • 担保品抵扣：再保险人提供的担保品（信用证、现金担保、信托资产等）可抵扣应收分保账款，降低违约风险敞口
穿透后的再保险资产违约风险公式 MC再保资产违约 = Σ(应收分保账款i - 担保品i) × 最终再保险人i信用因子
对每家最终再保险人 i 分别计算后加总
担保品可抵扣净敞口，降低资本要求

二期改革概览 Phase II Reforms Key Changes in Reinsurance Risk

C-ROSS 二期在再保险风险计量方面进行了多项重要改革，核心方向是更严格的认可标准、更审慎的风险因子、更透明的穿透计量——强化对未评级再保险人的惩罚、强调穿透原则、区分境内外再保险人风险。

改革领域 一期做法 二期改革
再保险资产认可标准 认可标准相对宽松 更加严格，对再保险人资质要求提高
未评级再保险人 因子较高但无专项惩罚 新增惩罚性因子（10%）
再保险风险因子 因子相对较低 整体上调，更加审慎
穿透计量 穿透要求有限 强调"应穿尽穿"原则
境外再保险人 与境内统一因子 区分境内外再保险人风险因子

变化1：再保险资产认可标准更加严格 Stricter Recognition Standards Tighter Admitted Asset Rules

一期问题

一期规则下，再保险资产的认可标准相对宽松——即使再保险人信用质量较差，只要满足基本的合约要求，应收分保账款即可全额认可。这导致部分保险公司通过低质量再保险人安排"纸面分保"——表面分出风险，实际再保险人无力赔付，风险仍留在原保险公司。

二期改革

二期对再保险资产的认可标准进行了更加严格的规定：① 再保险人须满足最低资本充足率要求；② 应收分保账款按再保险人信用质量差异化认可——低评级或未评级再保险人的应收分保账款须打折认可；③ 要求提供担保品的再保险安排享受更高认可比例。这些措施提高了再保险资产的真实质量。

变化2：新增未评级再保险人惩罚性因子 Unrated Reinsurer Penalty 10% Punitive Factor

改革背景

一期对未评级再保险人的风险因子虽高于评级再保险人，但差距不够大，未能有效阻止保险公司使用未评级再保险人。部分公司通过未评级的关联再保险人进行风险转移安排，实际上风险仍在集团内部，再保险的分散效果存疑。

二期改革

二期对未评级再保险人适用10%的惩罚性信用风险因子——是AAA级再保险人的20倍。这一惩罚性因子使得使用未评级再保险人的资本成本极高，倒逼保险公司：① 选择有外部评级的再保险人；② 要求未评级再保险人提供充足担保品；③ 减少对未评级再保险人的依赖。

未评级再保险人惩罚效果对比 假设应收分保账款 = 10,000 万

AAA级：MC = 10,000 × 0.5% = 50 万
未评级：MC = 10,000 × 10% = 1,000 万

差异 = 950 万，惩罚效果显著

变化3：再保险风险因子整体上调 Factor Increase More Prudent Capital

改革要点

二期对再保险风险的各项因子进行了整体上调：① 再保险人信用风险因子各评级档次均有所上升；② 负债波动风险因子适度上调；③ 因子调整使得再保险风险最低资本整体上升，更审慎地反映再保险安排的风险。上调幅度在10%-30%之间，因评级档次和业务类型而异。

变化4：强调"应穿尽穿"原则 Look-Through Principle Mandatory Penetration

一期问题

一期对再保险安排的穿透要求有限，部分保险公司通过转分保和复杂再保险结构隐藏最终风险承担方。例如：A保险公司将业务分给B再保险人，B又将业务转分给C再保险人（C可能信用质量较差），但在一期的计量框架下，A公司仅按B再保险人的评级计量违约风险，未能反映C的真实信用质量。

二期改革

二期通过第7号规则强调"应穿尽穿"原则：① 转分保须穿透至最终再保险人，按最终再保险人信用评级计量；② 复杂再保险结构须逐层穿透；③ 无法穿透的再保险安排适用惩罚性因子；④ 鼓励保险公司选择结构简单、可穿透的再保险安排。这使得再保险风险的计量更加真实透明。

变化5：境外再保险人风险因子区分 Onshore vs Offshore Factors Jurisdiction-Based Differentiation

改革要点

二期对境外再保险人的风险因子进行区分：① 境外再保险人须满足注册地监管机构的偿付能力要求，并经中国监管认可；② 境外再保险人的信用风险因子可能略高于同等评级的境内再保险人，反映跨境监管协调的额外风险；③ 对注册在低监管标准地区的境外再保险人施加额外风险因子。这一改革促进了中国再保险市场的规范发展。

再保险人类型 AAA级因子 未评级因子 说明
境内再保险人 0.5% 10.0% 中国境内注册的再保险人
境外再保险人（高监管标准地区） 0.5% 10.0% 注册在高监管标准地区的境外再保险人

MC再保负债波动 300 30,000 × 1.0%

注：再保险风险的加法聚合不含分散效应——资产违约风险和负债波动风险在性质上不同，统计上不显著相关。
4 保险风险汇总（衔接第5号和第2号）Insurance Risk Aggregation

将寿险保险风险（第5号）、非寿险保险风险（第4号）和再保险风险（第6号）汇总，得到完整的保险风险最低资本。

来自前序案例的数据

MC寿险（第5号）= 14,200 万（死亡4,000 + 长寿2,700 + 疾病5,000 + 退保2,500 + 费用1,200，经5×5矩阵聚合）
MC非寿险（第4号）= 0 万（西红人寿为纯寿险公司，无非寿险业务）
MC再保（第6号，本案例）= 570 万

保险风险最低资本汇总：
MC保险 = MC寿险 + MC非寿险 + MC再保
  = 14,200 + 0 + 570
  = 14,770 万
风险类别 规则号 MC(万) 说明
寿险保险风险 第5号 14,200 死亡+长寿+疾病+退保+费用 聚合
非寿险保险风险 第4号 0 纯寿险公司，无非寿险业务
再保险风险 第6号 570 资产违约270 + 负债波动300
MC保险 合计 14,770 加法聚合
注：对于纯寿险公司（如西红人寿），MC保险 ≈ MC寿险 + MC再保 = 14,770 万。再保险风险占保险风险的 3.9%（570/14,770）。
5 完整偿付能力链条回顾 Full Solvency Chain Review

将再保险风险纳入完整偿付能力计算链条，回顾第1号至第6号的数值关系。

规则号 计算内容 结果(万) 在充足率中的位置
第1号 实际资本 = 认可资产 - 认可负债 57,000 分子
第3号 寿险合同负债 = BEL + RM + 未决赔款 4,950 分子中认可负债的子项
第5号 寿险保险风险（5项子风险聚合） 14,200 分母中保险风险的主项
第6号 再保险风险（资产违约 + 负债波动） 570 分母中保险风险的附加项
第4+5+6号 MC保险 = MC寿险 + MC非寿险 + MC再保 14,770 分母中保险风险维度合计
第2号 最低资本 = MC可资本化 × (1 + k) 20,081 分母
完整闭环验证

第1号→第3号→第5号→第6号→第2号构成完整的偿付能力计算链条：

  • 第1号（分子）：实际资本 57,000 万元
  • 第3号（负债）：寿险合同负债 4,950 万元（影响分子中认可负债）
  • 第5号+第6号（保险风险）：MC保险 = 14,200 + 570 = 14,770 万元（分母中保险风险维度）
  • 第2号（分母）：最低资本 20,081 万元（含保险+市场+信用+控制风险）

综合偿付能力充足率 = 57,000 / 20,081 = 284%
核心偿付能力充足率 = 46,800 / 20,081 = 233%

西红人寿偿付能力充足，远高于监管要求（核心≥50%、综合≥100%）。再保险风险（570万）占保险风险的3.9%，占最低资本的2.8%，比例较小但不可忽视——主要风险来源是未评级再保险人的惩罚性因子（200万）。
