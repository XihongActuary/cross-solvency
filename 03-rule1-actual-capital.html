第1号：实际资本 —— 偿付能力充足率的分子

Actual Capital / Available Capital
Pillar I · 第一支柱 认可资产 - 认可负债 四级资本分级 保单未来盈余35%限额

实际资本的定义 Definition Actual Capital / Available Capital

实际资本，又称可用资本（Available Capital），是指保险公司在持续经营或破产清算状态下可以吸收损失的财务资源。它是偿付能力充足率公式的分子，直接决定保险公司是否满足监管的资本要求。

实际资本基本公式 Actual Capital = Admitted Assets - Admitted Liabilities
实际资本 = 认可资产 - 认可负债
认可资产：按照监管标准可以计入实际资本的资产（排除商誉、递延所得税资产等非认可资产）
认可负债：按照监管标准计算的负债（寿险合同按第3号规则评估，非寿险以财务账面价值）
"持续经营 + 破产清算"双视角

实际资本同时承担两种功能：① 持续经营视角——在正常经营中吸收非预期损失，保证公司稳健运行；② 破产清算视角——在极端情况下对保单持有人提供赔付保障。因此实际资本必须具备"真实的损失吸收能力"，并非所有账面资产都计入。

资本分级结构 Capital Tiering Structure Four-Tier Hierarchy

C-ROSS II 借鉴 Basel III / Solvency II 的资本分级理念，将实际资本按损失吸收能力由高到低分为四级：核心一级、核心二级、附属一级、附属二级。资本层级越高，吸收损失的能力越强，监管限制也越严格。

资本层级 英文 简写 主要构成 损失吸收能力
核心一级 Core Tier 1 CET1 实收资本、资本公积、留存收益、剩余期限 > 30年的保单未来盈余 最强
核心二级 Additional Tier 1 AT1 剩余期限 10-30年的保单未来盈余 强
附属一级 Tier 2 T2 剩余期限 5-10年的保单未来盈余 + 符合条件的资本工具 中等
附属二级 Tier 3 T3 剩余期限 < 5年的保单未来盈余 + 次级债 弱
资本分级汇总 实际资本 = 核心资本 + 附属资本
核心资本 = 核心一级资本 (CET1) + 核心二级资本 (AT1)
附属资本 = 附属一级资本 (T2) + 附属二级资本 (T3)

关键限额约束 Key Constraints Capital Limits

为防止保险公司以低质量资本"充数"，C-ROSS II 对各层级资本设置了严格的数量限额约束。这些约束确保高质量资本在总资本中保持合理比重。

限额规则 公式 说明
核心资本中保单未来盈余限额 保单未来盈余纳入核心资本部分 ≤ 核心资本 × 35% 防止保险公司将长尾业务的未来利润过度提前计入核心资本，增强核心资本的真实性
附属资本限额 附属资本 ≤ 核心资本 确保高质量资本在总资本中至少占50%，防止资本结构"倒挂"
核心二级资本限额 核心二级资本 ≤ 核心一级资本 × 35% 限制次级质量的"核心资本"比重，保证核心一级资本的主导地位
超限处理规则

当某层级资本超过限额时，须将超额部分向下级层级转移（例如核心二级超额则转入附属一级），直至满足限额要求；若向下转移后附属资本也超限，则超出部分不计入实际资本。这一机制确保了资本结构的"金字塔"形状——高质量资本在上，低质量资本在下。

保单未来盈余的分级计入 Future Profits Tiering Key Innovation of Phase II

保单未来盈余（Future Profits in Current Policies）是指现有保单未来预期产生的利润的现值。在 C-ROSS 一期中，保单未来盈余全额计入核心资本，被批评为虚增资本。二期改革引入了按剩余期限分级计入的创新机制。

保单未来盈余分级计入规则 保单未来盈余 → 按剩余期限分四档：
剩余期限 > 30年 → 计入核心一级资本 (CET1)
剩余期限 10-30年 → 计入核心二级资本 (AT1)
剩余期限 5-10年 → 计入附属一级资本 (T2)
剩余期限 < 5年 → 计入附属二级资本 (T3)
设计原理

剩余期限越长，未来利润的不确定性越大、变现时间越远，损失吸收能力越弱；反之剩余期限越短，利润实现的确定性越高。将长期未来盈余计入更低层级资本，可防止保险公司将"远期纸上利润"当作"即期可用资本"使用，从根本上提升了实际资本的真实性和审慎性。

认可资产 Admitted Assets Recognition Standards

认可资产是实际资本公式的减项之一（实际资本 = 认可资产 - 认可负债）。C-ROSS II 对认可资产的认定以账面价值为基础，但对部分资产设有特殊规定，以反映资产的真实可变现价值与风险特征。

一般原则 General Principles

  • 以账面价值为基础计量（与会计准则一致）
  • 排除非认可资产：商誉、递延所得税资产、无形资产（单独列示的除外）、待处理财产损溢等
  • 对部分资产按认可比例或特殊估值方法调整

特殊资产规定 Special Provisions

资产类别 英文名称 认可规定
投资性房地产 Investment Real Estate 按成本模式计量（二期变化，一期为公允价值），评估增值不再计入实际资本
长期股权投资 Long-term Equity Investment 对联营/合营企业按权益法核算并考虑减值；对子公司（控制权）100%全额扣除，认可价值为 0（通过合并报表处理）
交易性金融资产 Trading Financial Assets 按公允价值计量，认可比例一般为 100%
持有至到期投资 Held-to-maturity Investments 按摊余成本计量，须考虑减值准备
应收款项 Receivables 按账面价值扣除坏账准备后净额，账龄超过一定期限的按比例认可
现金及银行存款 Cash & Bank Deposits 认可比例 100%（限制存款于非合格金融机构的部分）
"穿透"原则

对基础资产不透明的投资产品（如部分资管产品、信托计划、私募基金），须按照第7号规则"应穿尽穿"原则进行穿透，识别底层资产后按相应资产类别认定认可价值。无法穿透的资产适用惩罚性资本要求。

认可负债 Admitted Liabilities Liability Recognition

认可负债是实际资本公式的另一减项。C-ROSS II 对寿险与非寿险业务采用不同的认可负债评估标准。

业务类型 评估标准 说明
寿险合同负债 按第3号规则评估 采用"最优估计 + 风险边际"的计量模型，折现率采用750日移动平均国债收益率曲线 + 终极利率4.5%
非寿险负债 以财务报表账面价值为准 未到期责任准备金、未决赔款准备金按财务准则确认，不另作精算调整
其他负债 以财务报表账面价值为准 包括应付账款、其他应付款等
寿险合同负债评估模型（第3号规则） 寿险合同负债 = 最优估计准备金 + 风险边际
最优估计：未来现金流的概率加权现值（折现率=750日移动平均国债收益率+终极利率4.5%）
风险边际：为反映未来现金流不确定性而附加的缓冲（通常采用分位法或情景法计算）

所得税准备 Income Tax Provision Deferred Tax Asset Treatment

所得税准备的认定遵循审慎性原则，要求保险公司有合理的预期能够在未来实现相应的应纳税所得额。

所得税准备确认规则

保险公司连续三年应纳税所得额为正的，应确认相应的所得税准备（递延所得税负债）；否则不予确认。这一规则防止保险公司利用递延所得税资产虚增实际资本。

为何要确认所得税准备？

认可负债中包含所得税准备，是因为在极端情况下（如清算或重大损失事件），保险公司可能需要支付或承担相应的所得税义务。将这些潜在税负计入认可负债，可使实际资本更加审慎、保守，避免高估资本实力。

保单未来盈余归入规则 Future Profits Classification Tiering by Remaining Maturity

保单未来盈余按剩余期限分四档归入相应资本层级，这是 C-ROSS II 第1号规则的核心创新之一。

剩余期限 归入资本层级 说明
> 30年 核心一级 (CET1) 超长期未来利润，与实收资本、留存收益同列最高层级
10-30年 核心二级 (AT1) 长期未来利润，吸收损失能力较强
5-10年 附属一级 (T2) 中期未来利润，吸收损失能力中等
< 5年 附属二级 (T3) 短期未来利润，吸收损失能力较弱
保单未来盈余分级公式 FP_total = FP_{>30y} + FP_{10-30y} + FP_{5-10y} + FP_{<5y}
FP_{>30y} → CET1；FP_{10-30y} → AT1；FP_{5-10y} → T2；FP_{<5y} → T3
同时受 35% 限额约束：纳入核心资本的保单未来盈余 ≤ 核心资本 × 35%
"剩余期限"的定义

剩余期限 = 负债评估日 - 保单剩余保险期间终止日。对于年金等长期险业务，由于保险期间可能跨越数十年，未来盈余主要归入核心一级；对于短期健康险、意外险业务，未来盈余主要归入附属二级。这一机制实质上将资本质量与业务久期挂钩。

二期改革概览 Phase II Reforms Key Changes from Phase I

C-ROSS 二期（Phase II）相较一期（Phase I）在实际资本认定方面进行了系统性审慎化改革。核心思路是"挤水分、提质量、防套利"——挤掉虚增资本的水分，提升资本的真实损失吸收能力，防范资本套利行为。

改革领域 一期做法 二期改革
保单未来盈余 全额计入核心资本 按剩余期限分四档（>30年/10-30年/5-10年/<5年）分别计入核心一级、核心二级、附属一级、附属二级
投资性房地产 按公允价值计量，评估增值计入实际资本 按成本模式计量，评估增值不再计入实际资本
长期股权投资（子公司） 按权益法部分认可 100%全额扣除，认可价值为 0（通过合并报表处理子公司风险）
核心资本限额 无保单未来盈余占比限制 新增核心资本中保单未来盈余 ≤ 35% 的限额
上市公司股票 统一按公允价值认可 非蓝筹股须按减值规则处理，计提减值影响认可价值

变化1：保单未来盈余分级 Future Profits Tiering Most Significant Reform

一期问题

一期规则下，保单未来盈余全额计入核心资本。这导致保险公司可以将长期业务的远期预期利润全部当作"即期可用资本"，严重虚增了核心资本。对于长期储蓄型业务占比高的寿险公司，未来盈余可能占核心资本的50%以上，但这些利润要在数十年后才能逐步实现，根本无法应对即期损失。

二期改革

二期将保单未来盈余按剩余期限分四档：>30年 → 核心一级；10-30年 → 核心二级；5-10年 → 附属一级；<5年 → 附属二级。同时叠加35%限额，确保纳入核心资本的保单未来盈余不超过核心资本的35%。这一改革显著压降了虚增资本，促使保险公司依靠真实股东投入和经营积累。

影响示例 假设某寿险公司保单未来盈余 100 亿元，期限结构：>30年 30亿、10-30年 40亿、5-10年 20亿、<5年 10亿
一期： 100亿全部计入核心资本
二期： 核心一级 30亿 + 核心二级 40亿 + 附属一级 20亿 + 附属二级 10亿
若核心资本限额 35% 触发，进一步压缩核心资本中的未来盈余金额

变化2：投资性房地产成本模式 Real Estate Cost Model No More Fair Value Uplift

二期要求投资性房地产按成本模式后续计量，评估增值不再计入实际资本。

改革背景

一期允许投资性房地产按公允价值计量，评估增值计入实际资本。在房地产市场上涨周期，部分保险公司通过频繁重估房地产增值大幅"充胖"实际资本，但这些增值并未实现、存在回调风险，且流动性差。二期改为成本模式后，房地产增值部分须在实际资本中剔除，防止资本虚增。

变化3：子公司长投全额扣除 Subsidiary Investment Deduction Full Deduction Rule

二期对保险公司拥有控制权的子公司长期股权投资实施100%全额扣除，认可价值为 0。

扣除逻辑

子公司风险已通过合并报表方式纳入集团偿付能力监管（第19号规则）。若同时在母公司层面认可长投价值，将造成同一笔资本"双重计算"。全额扣除可避免资本重复计入，确保集团层面资本真实。对于不纳入合并范围的联营、合营企业，仍按权益法认可（考虑减值）。

变化4：核心资本35%限额 35% Cap on Future Profits New Quantitative Limit

二期新增核心资本中保单未来盈余 ≤ 35% 的限额约束，这是一期没有的规则。

35% 限额公式 保单未来盈余纳入核心资本部分 ≤ 核心资本 × 35%
即 (CET1 中的 FP + AT1 中的 FP) ≤ (CET1 + AT1) × 35%
超出部分向下转移：核心二级 → 附属一级；附属一级 → 附属二级
限额的政策意图

35%限额与保单未来盈余分级机制"双保险"：分级机制限制了未来盈余的质量层级，35%限额限制了未来盈余在核心资本中的数量占比。两者共同作用，确保核心资本主要由"真金白银"（实收资本、资本公积、留存收益）构成，而非"纸上利润"。

变化5：上市公司股票减值规则 Stock Impairment Non-blue-chip Impairment

二期对上市公司股票实施差异化认可规则：蓝筹股按公允价值认可，非蓝筹股须按减值规则处理。

减值规则要点
  • 蓝筹股（沪深300成分股等）：按公允价值认可，不强制减值
  • 非蓝筹股：当股价持续低于成本价一定幅度时，须计提减值并相应调减认可价值
  • 减值规则与会计准则的减值逻辑有所差异，体现监管的审慎性
  • 该规则限制了保险公司通过配置高风险股票"博收益"的行为

计算案例：西红人寿保险公司 Worked Example Anxin Life Insurance Co.

公司背景 Company Background

西红人寿保险公司（Anxin Life Insurance Co., Ltd.），一家虚构的中型寿险公司，以长期储蓄型业务为主。
评估日期：2024年12月31日　|　单位：万元

1 认可资产计算 Admitted Assets Calculation

以账面价值为基础，对部分资产按特殊规定调整。

资产类别 账面价值 认可规定 认可价值
银行存款 50,000 认可比例 100% 50,000
国债 80,000 认可比例 100% 80,000
企业债 60,000 认可比例 100% 60,000
上市股票（蓝筹） 30,000 蓝筹股按公允价值认可 30,000
投资性房地产（成本） 20,000 二期：成本模式（公允价值增值 5,000 不计入） 20,000
子公司长投（控制权） 40,000 100%全额扣除（通过合并报表处理） 0
合计认可资产 280,000 账面 280,000 → 认可 240,000 240,000
认可资产合计 = 50,000 + 80,000 + 60,000 + 30,000 + 20,000 + 0 = 240,000 万元
注：子公司长投 40,000 万元全额扣除；投资性房地产公允价值增值 5,000 万元不计入。
2 认可负债计算 Admitted Liabilities Calculation

寿险合同负债按第3号规则评估（最优估计 + 风险边际）。

负债类别 评估标准 认可价值
寿险合同负债（最优估计） 第3号规则（750日国债收益率+终极利率4.5%） 160,000
风险边际 反映未来现金流不确定性 12,000
其他负债 财务报表账面价值 8,000
所得税准备 连续三年应纳税所得额为正，予以确认 3,000
合计认可负债 各项加总 183,000
认可负债合计 = 160,000 + 12,000 + 8,000 + 3,000 = 183,000 万元
3 实际资本计算 Actual Capital Calculation
实际资本 = 认可资产 - 认可负债 = 240,000 - 183,000 = 57,000 万元
实际资本 = 57,000 万元
此为限额调整前的"名义实际资本"，接下来进行资本分级与限额检查。
4 资本分级（调整前）Capital Tiering (Pre-adjustment)

将各项资本来源按性质归入相应资本层级。

资本来源 金额 归入层级 说明
实收资本 + 资本公积 20,000 核心一级 股东投入，最高质量资本
留存收益 10,000 核心一级 历年经营积累
保单未来盈余（>30年期） 8,000 核心一级 剩余期限 > 30年
保单未来盈余（10-30年期） 10,000 核心二级 剩余期限 10-30年
保单未来盈余（5-10年期） 6,000 附属一级 剩余期限 5-10年
保单未来盈余（<5年期） 3,000 附属二级 剩余期限 < 5年
合计 57,000 名义实际资本（限额调整前）

35% 限额检查

核心资本 = 核心一级 + 核心二级 = (20,000 + 10,000 + 8,000) + 10,000 = 48,000 万元
纳入核心资本的保单未来盈余 = 8,000 + 10,000 = 18,000 万元
占比 = 18,000 / 48,000 = 37.5% > 35% 限额 → 需调整
保单未来盈余占核心资本 37.5%，超过 35% 限额，须将超额部分从核心二级转入附属一级。
5 限额调整后最终资本结构 Final Capital Structure (Post-adjustment)

核心资本中允许的保单未来盈余上限 = 核心资本 × 35%。超出部分向下转移。

核心资本中允许的保单未来盈余上限 = 48,000 × 35% = 16,800 万元
当前核心一级中保单未来盈余 = 8,000 万元
核心二级最多可保留 = 16,800 - 8,000 = 8,800 万元（原 10,000，超额 1,200）
超额部分 1,200 万元 → 从核心二级转入附属一级
资本层级 调整前 调整后 构成明细（调整后）
核心一级 (CET1) 38,000 38,000 实收资本+资本公积 20,000 + 留存收益 10,000 + FP(>30年) 8,000
核心二级 (AT1) 10,000 8,800 FP(10-30年) 10,000 - 转出 1,200 = 8,800
附属一级 (T2) 6,000 7,200 原 FP(5-10年) 6,000 + 从核心二级转入 1,200 = 7,200
附属二级 (T3) 3,000 3,000 FP(<5年) 3,000（不变）
核心资本合计 48,000 46,800 核心一级 38,000 + 核心二级 8,800
实际资本合计 57,000 57,000 核心资本 46,800 + 附属资本 10,200（总额不变）

限额复核验证

[验证] 35% 限额检查：
纳入核心资本的保单未来盈余 = FP(>30年) + FP(10-30年, 调整后)
= 8,000 + 8,800 = 16,800 万元
核心资本 = 38,000 + 8,800 = 46,800 万元
占比 = 16,800 / 46,800 = 35.9% ≈ 35% ✓ 达标
[验证] 附属资本 ≤ 核心资本：
附属资本 = 附属一级 7,200 + 附属二级 3,000 = 10,200 万元
核心资本 = 46,800 万元
10,200 ≤ 46,800 → 达标 ✓
最终结果：核心资本 46,800 万元 ｜ 实际资本 57,000 万元 ｜ 保单未来盈余占比 35.9% ≈ 35% ✓
案例结论

经过5步计算，西红人寿的实际资本为 57,000 万元，其中核心资本 46,800 万元（核心一级 38,000 + 核心二级 8,800），附属资本 10,200 万元（附属一级 7,200 + 附属二级 3,000）。保单未来盈余占核心资本比重经调整后约为 35%，满足 35% 限额要求。本案例展示了 C-ROSS II 实际资本认定的全流程：认可资产扣除 → 认可负债加总 → 实际资本计算 → 资本分级 → 限额调整。
