第18号：偿付能力报告 —— 监管数据的载体与审计基础

Solvency Report
Pillar III · 第三支柱 季度报告 临时报告 一体观会计

偿付能力报告的定义 Definition

偿付能力报告是保险公司向监管机构报送的，反映偿付能力状况和风险管理情况的综合性报告。偿付能力报告是监管机构获取公司偿付能力数据的主要渠道，也是第二支柱评估（SARMRA、IRR）和第三支柱披露的信息基础。

报告 vs 披露

第18号（报告）：公司 → 监管机构，监管报送，面向监管内部使用
第15号（披露）：公司 → 公众，公开披露，面向市场参与者
偿付能力报告的内容更详细、数据更全面，是公开披露的数据来源。

报告体系 Report System

报告类型频率报送时限内容
季度偿付能力报告每季度季后25日内完整偿付能力数据表+附注
偿付能力快报每季度季后10日内核心指标快报（充足率、资本）
年度偿付能力报告每年年后4个月内完整年度报告+审计报告+SARMRA自评估
临时报告按需事件后10日内重大事项临时报告

一体观会计 One-View Accounting

一体观会计的核心要求

偿付能力报告中的财务数据应与财务报表保持一致（"一体观"），即偿付能力报告基于通用会计准则（CAS）的财务数据，在此基础上进行偿付能力调整。这一要求确保了偿付能力数据与财务数据的一致性和可审计性。

具体调整包括：资产认可价值调整（如投资性房地产按成本模式）、负债认可价值调整（如准备金最优估计）、保单未来盈余分级、递延所得税调整等。

临时报告触发条件 Triggers

  • 偿付能力充足率低于100%
  • 实际资本下降超过20%
  • IRR评级下调
  • 重大投资损失（超净资产5%）
  • 重大再保险安排变更
  • 发行或赎回资本补充工具
  • 监管行政处罚
  • 重大关联交易

二期核心变化 Key Changes

快报制度新增

二期新增偿付能力快报制度，季后10日内报送核心指标，提高监管时效性。

报告内容扩充

新增保单未来盈余分级、穿透式计量结果、资本规划等章节。

一体观会计强化

二期明确偿付能力报告与财务报表的衔接关系，减少"两套账"问题。

审计要求明确

年度报告须经外部审计师审计，审计意见随报告报送。

临时报告制度化

二期将临时报告从"原则要求"细化为具体触发条件清单和时限。

数字化报送

推动XBRL等结构化数据报送格式，提高数据质量和处理效率。

报告附注（摘要）

会计政策：本报告基于CAS财务数据编制，投资性房地产按成本模式计量，保单未来盈余按剩余期限分四级计入相应资本层级。

精算假设：折现率采用750日移动平均国债收益率曲线（终极利率4.5%），死亡率采用CL2010-2013生命表，退保率基准8%。

重大事项：本季度无重大事项。上季度发行5,000万元资本补充债券，已在临时报告中报送。

审计意见

年度报告经外部审计师审计，审计意见为"无保留意见"。审计师确认：偿付能力报告数据与财务报表一致，资本计量方法符合监管要求，数据质量可靠。
