第一部分：选择题 Multiple Choice (10 Questions)

每题4个选项，选择最正确的答案。提交后显示正确答案和解析。

1C-ROSS II（偿二代二期）的发布文号和实施时间是？
A银保监发〔2015〕15号，2015年实施
B银保监发〔2021〕51号，2022年Q1起执行
C银保监发〔2018〕42号，2019年实施
D银保监发〔2020〕20号，2021年实施
答案：B。C-ROSS II于2021年12月30日发布（银保监发〔2021〕51号），自2022年第一季度起执行。文号51号是文件编号，不是20项规则。
2核心偿付能力充足率的监管底线是？
A50%
B核心充足率 ≥ 50%，综合充足率 ≥ 100%
C100%
D150%
答案：B。C-ROSS II要求核心偿付能力充足率 ≥ 50% 且 综合偿付能力充足率 ≥ 100%，两个指标同时达标。注意不是单一指标。
3保单未来盈余在二期中如何计入资本？
A全部计入核心一级资本
B全部计入附属资本
C按剩余期限分四档计入不同资本层级，核心资本内限额 ≤35%
D不计入实际资本
答案：C。保单未来盈余按剩余期限分四档：>30年→核心一级、10-30年→核心二级、5-10年→附属一级、<5年→附属二级。计入核心资本的部分有35%的限额约束。
4寿险负债评估的折现率曲线采用什么基准？
A当日国债收益率
B750日移动平均国债收益率 + 终极利率4.5%
C30日移动平均收益率
D银行间同业拆借利率（Shibor）
答案：B。寿险负债评估用750日移动平均国债收益率曲线（约3年），加终极利率4.5%，平滑市场波动。而利率风险最低资本用60日移动平均曲线（更敏感）。
5SARMRA评估覆盖多少个风险管理领域？
A5个
B7个
C9个
D12个
答案：C。二期SARMRA评估9大领域：风险治理、风险偏好与容忍度、风险识别与评估、风险控制与缓释、风险监控与报告、风险管理工具与信息系统、风险文化、压力测试、应急管理。
6IRR风险综合评级分为几类？
A3类（A/B/C）
B4类（A/B/C/D）
C5类（A/B/C/D/E）
D2类（合格/不合格）
答案：B。IRR分A/B/C/D四类。A类风险最小（常规监管），D类风险最大（接管重组）。综合评级遵循"就低不就高"原则——min(可资本化, 难以资本化)。
7"应穿尽穿、穿透到底"是哪个规则的核心原则？
A第1号 实际资本
B第2号 最低资本
C第7号 穿透计量
D第8号 市场风险
答案：C。第7号"市场风险和信用风险的穿透计量"是二期新增规则，核心原则是"应穿尽穿、穿透到底"——对所有非基础资产逐层穿透至基础资产，无法穿透适用惩罚性资本要求。
8利率风险最低资本使用什么折现率曲线？
A750日移动平均
B60日移动平均
C当日收益率
D365日移动平均
答案：B。二期创新：负债评估用750日MA（平滑稳定），但利率风险最低资本用60日MA（更敏感），增强对市场变化的敏感性。两条曲线分开使用是二期的重要变化。
9集团偿付能力计量中"内部交易消除"的主要目的是？
A简化计算
B防止资本重复计算和虚假资本
C降低集团最低资本
D提高集团充足率
答案：B。集团内部交易（内部债、内部再保险、交叉持股）会虚增集团资本。消除机制挤出这些"水分"，确保集团偿付能力反映真实外部资本支撑能力。
10偿付能力信息公开披露（第15号）的季度披露时限是？
A季度结束后10日内
B季度结束后30日内
C季度结束后60日内
D季度结束后90日内
答案：B。季度公开披露在季度结束后30日内完成。快报在10日内报送监管，公开披露在30日内发布。年度披露在年度结束后4个月内完成。

第二部分：计算填空题 Calculation (5 Questions)

基于西红人寿的数据（实际资本57,000万元，最低资本20,081万元）进行计算。

1西红人寿综合偿付能力充足率 = 57,000 / 20,081 × 100% = %
答案：284%。综合偿付能力充足率 = 实际资本 / 最低资本 × 100% = 57,000 / 20,081 = 283.8% ≈ 284%。
2若核心资本为46,740万元，核心偿付能力充足率 = 46,740 / 20,081 × 100% = %
答案：233%。核心偿付能力充足率 = 核心资本 / 最低资本 = 46,740 / 20,081 = 232.8% ≈ 233%。
3SARMRA评分55分（加征8%），控制风险MC = 20,081 × 8% = 万元
答案：1,606万元。控制风险MC = 基础MC × 加征系数 = 20,081 × 8% = 1,606万。加征后最低资本合计 = 20,081 + 1,606 = 21,687万。
4压力情景下实际资本47,233万、最低资本23,500万，综合充足率 = %
答案：201%。压力情景下综合充足率 = 47,233 / 23,500 = 200.9% ≈ 201%。从基准284%降至201%，下降83个百分点（逆周期叠加情景）。
5流动资产49,050万、流动负债31,000万，流动性监管指标 = %
答案：158%。流动性监管指标 = 流动资产 / 流动负债 × 100% = 49,050 / 31,000 = 158.2% ≈ 158%。高于100%监管要求。
