第10号：压力测试 —— 极端情景下的偿付能力评估

Stress Testing
Pillar I · 第一支柱 必测情景 自测情景 可选情景 充足率变化

压力测试的定义 Definition Stress Testing

压力测试是保险公司评估在极端不利情景下偿付能力状况的风险管理工具。通过对各类风险设定极端但合理的冲击情景，量化风险对实际资本和最低资本的影响，评估公司在压力情境下是否仍能维持偿付能力充足。压力测试是第一支柱风险计量的重要补充，也是第二支柱风险管理要求的核心组成。

充足率变化公式 充足率变化 = ( 实际资本情景 - 最低资本情景 ) / 最低资本情景 × 100% - 基准充足率
基准充足率 = 正常情景下的综合偿付能力充足率
正值表示充足率下降，负值表示充足率上升
压力测试的核心目的

压力测试回答一个关键问题："如果极端不利事件发生，公司是否仍然具有足够的偿付能力？"正常情景下的偿付能力充足率仅反映"平均"风险水平，无法揭示尾部风险。压力测试通过设定极端情景，弥补了VaR框架（99.5%置信度）无法覆盖0.5%尾部事件的不足，帮助公司和监管机构识别尾部风险暴露。

三类情景 Three Scenario Types Mandatory / Self-Defined / Optional

1. 必测情景 Mandatory Scenarios — 监管规定

必测情景是监管规定的最低压力测试情景，所有保险公司必须执行。二期规定的必测情景共9个，覆盖市场风险、信用风险和保险风险的主要风险类型。必测情景的参数和冲击幅度由监管统一规定，确保行业可比性。

必测情景的强制要求

必测情景是偿付能力报告的组成部分，测试结果需随季度报告报送监管机构。如必测情景下充足率低于100%，保险公司需提交压力测试报告并说明应对措施。

2. 自测情景 Self-Defined Scenarios — 公司自设

自测情景是公司根据自身风险特征设计的压力测试情景。监管要求公司至少设计3个自测情景，反映公司面临的特定风险暴露。自测情景的设计基于公司风险评估结果，需经董事会风险管理委员会审议。

自测情景设计原则

自测情景应覆盖公司主要风险类型，反映公司业务结构和投资组合的特征。例如：① 产品集中度高的公司应设计产品风险专项情景；② 投资集中度高的公司应设计资产风险专项情景；③ 再保依赖度高的公司应设计再保险风险情景。

3. 可选情景 Optional Scenarios — 监管可选

可选情景是监管可选的附加情景，根据宏观经济环境和行业风险状况不定期发布。监管可在特定时期要求保险公司执行特定的可选情景测试，例如在市场剧烈波动时期要求执行额外压力测试。

压力测试流程 Stress Testing Process Five Steps

压力测试流程 识别风险 → 设计情景 → 量化影响 → 评估充足率 → 报告与应对
Step 1: 识别公司面临的主要风险类型
Step 2: 设计压力情景（必测+自测+可选）
Step 3: 量化各情景对实际资本和最低资本的影响
Step 4: 计算压力情景下的偿付能力充足率
Step 5: 编制压力测试报告，制定资本补充计划
流程说明

识别风险：基于ORSA（自身风险和偿付能力评估）结果，识别公司面临的主要风险类型和风险敞口。
设计情景：针对识别出的风险，设计必测、自测和可选情景，确定冲击参数。
量化影响：将情景参数输入估值和资本计量模型，计算各情景下实际资本和最低资本的变化。
评估充足率：计算压力情景下的核心和综合偿付能力充足率，与基准充足率比较。
报告与应对：编制压力测试报告，如充足率低于100%需制定资本补充计划。

压力测试与资本规划 Connection to Capital Planning Link to Rule 14

压力测试结果是资本规划（第14号）的重要输入。压力测试揭示了公司在极端情景下的资本缺口，资本规划据此制定资本补充方案，确保公司在各种情景下均能维持偿付能力充足。

压力测试在偿付能力体系中的位置

压力测试 → 识别极端情景资本缺口 → 资本规划（第14号） → 制定资本补充方案 → 维持偿付能力充足。压力测试是连接第一支柱（量化要求）和第二支柱（风险管理）的桥梁——它既使用第一支柱的计量框架，又服务于第二支柱的风险管理要求。

二期规定9个必测情景，覆盖市场风险、信用风险、保险风险和集中度风险。各情景的冲击参数由监管统一规定。

情景设计原理

各必测情景的冲击幅度基于历史极端事件设定：① 股票-30%参考2015年股市异常波动；② 利率±100bp覆盖利率大幅波动的情景；③ 房地产-15%反映房地产市场调整风险；④ 退保翻倍反映流动性危机情景；⑤ 逆周期叠加模拟多风险同时爆发的系统性风险。

自测情景设计 Self-Defined Scenarios Company-Specific

公司需根据自身风险特征设计至少3个自测情景。自测情景应覆盖公司主要风险暴露，并考虑风险之间的传染效应。

自测情景设计原则 Design Principles

  • 风险导向：基于ORSA风险评估结果，针对公司最大风险暴露设计情景
  • 前瞻性：不仅考虑历史极端事件，还需考虑未来可能出现的风险
  • 反向压力测试：从"什么会导致公司偿付能力不足"出发，反推压力情景
  • 多风险叠加：考虑风险之间的传染和放大效应
自测情景示例

以寿险公司为例，典型的自测情景包括：① 利差损情景——长期低利率持续，新业务收益率低于定价假设；② 集中退保情景——声誉事件导致集中退保，现金流断裂；③ 信用违约潮情景——多个交易对手同时违约，信用损失激增。

情景测试频率 Testing Frequency Semi-Annual Minimum

测试频率要求 必测情景：至少每半年一次
自测情景：至少每年一次（建议每半年）
可选情景：监管要求时执行
重大事件触发：市场剧烈波动时立即执行
测试频率说明

压力测试频率至少为每半年一次，但建议公司根据自身风险特征提高测试频率。在以下情况应立即执行额外压力测试：① 金融市场剧烈波动；② 监管政策重大调整；③ 公司重大战略变化；④ 重大自然灾害或突发事件。

压力测试报告 Stress Testing Report Reporting Requirements

压力测试完成后需编制压力测试报告，报送董事会风险管理委员会和监管机构。报告内容包括：

  • 情景设计说明：各情景的假设、参数和冲击幅度
  • 量化影响结果：各情景下实际资本、最低资本和充足率的变化
  • 资本缺口分析：压力情景下的资本缺口及成因
  • 应对措施：资本补充计划和风险缓释措施
  • 管理层建议：基于测试结果的风险管理改进建议

二期改革概览 Phase II Reforms Key Changes in Stress Testing

C-ROSS二期在压力测试方面进行了多项重要改革，核心变化是必测情景数量增加、新增逆周期情景和压力测试纳入资本规划，同时要求建立压力测试管理制度。

改革领域 一期做法 二期改革
必测情景数量 6个必测情景 增至9个（新增3个）
逆周期情景 无多风险叠加情景 新增逆周期叠加情景
退保风险情景 无专项退保压力情景 新增退保率翻倍情景
集中度风险情景 无专项集中度压力情景 新增单一资产违约情景
资本规划衔接 压力测试结果与资本规划衔接不紧密 压力测试结果纳入资本规划（第14号）
管理制度 无专门管理制度要求 要求建立压力测试管理制度

变化1：必测情景从6个增至9个 Scenario Expansion 6 → 9

一期问题

一期压力测试的必测情景仅6个，覆盖的风险类型有限。一期的情景主要覆盖市场风险和信用风险，对保险风险和集中度风险的压力测试不足，无法全面反映公司面临的尾部风险。

二期改革

二期将必测情景从6个增至9个，新增3个情景：① 逆周期叠加情景——多风险同时爆发；② 退保率翻倍情景——流动性危机；③ 集中度风险情景——单一资产全额违约。新增情景覆盖了之前未纳入的压力维度，使压力测试更加全面。

变化2：新增逆周期情景 Countercyclical Scenario Multi-Risk Overlay

一期问题

一期压力测试主要针对单一风险，未考虑多风险同时爆发的系统性风险情景。实际金融危机中，往往是多种风险同时爆发——例如2008年金融危机中，股票暴跌、信用利差扩大、流动性枯竭同时发生。单一风险情景无法反映这种"尾部相依"效应。

二期改革

二期新增逆周期叠加情景——模拟股票下跌20%、利率下降50bp、退保率上升1.5倍同时发生的极端情景。该情景反映了经济下行周期中多风险叠加的系统性风险，是压力测试中冲击最大的情景之一。逆周期情景的参数虽低于单个必测情景，但多风险叠加效应使得综合冲击更为严重。

变化3：新增退保率翻倍和集中度风险情景 New Scenarios Surrender & Concentration

退保率翻倍情景 Surrender Rate Doubling

退保风险情景设计

退保率翻倍情景模拟声誉事件或市场恐慌导致的集中退保。退保率上升导致：① 准备金大量释放，但需支付退保金；② 现金流压力增大，可能被迫低价变卖资产；③ 投资收益下降。该情景对依赖新业务现金流的寿险公司冲击尤为显著。

单一资产违约情景 Single Asset Default

集中度风险情景设计

单一资产违约情景假设公司最大单一资产全额违约。该情景与第9号集中度风险最低资本衔接——第9号对超过总资产5%的单一交易对手暴露计提额外资本，压力测试进一步评估单一资产全额违约的极端影响。该情景促使公司关注投资集中度风险。

变化4：压力测试纳入资本规划 Capital Planning Integration Link to Rule 14

改革要点

二期要求将压力测试结果纳入资本规划（第14号）。如果压力测试显示在特定情景下充足率低于100%，公司需在资本规划中制定资本补充方案，包括：① 利润留存计划；② 股东增资计划；③ 发行资本补充工具；④ 风险缓释措施（如调整资产配置、增加再保）。这一改革使压力测试从"事后评估"转变为"前置规划"，强化了压力测试的实际管理价值。

变化5：建立压力测试管理制度 Management System Institutional Framework

制度要求

二期要求保险公司建立压力测试管理制度，明确：① 压力测试的组织架构和职责分工；② 情景设计、参数设定、量化分析的方法论；③ 测试频率和报告流程；④ 结果应用和资本规划衔接机制；⑤ 制度的定期回顾和更新机制。这一要求将压力测试从"一次性任务"提升为"常态化管理机制"。

计算案例：西红人寿 — 压力测试 Worked Example Xihong Life Insurance

公司背景 Company Background

西红人寿保险公司（Xihong Life Insurance Co., Ltd.），继续第1号和第2号案例的分析。
评估日期：2024年12月31日  |  单位：万元
本案例的压力测试基于第1号实际资本和第2号最低资本的基准数值。

基准情景（正常状态） Baseline Scenario

指标 数值（万元） 说明
实际资本 57,000 来自第1号案例
最低资本 20,081 来自第2号案例
核心偿付能力充足率 233% 核心资本 / 最低资本
综合偿付能力充足率 284% 实际资本 / 最低资本
教学说明 Educational Note

本案例为简化的教学示例，演示压力测试情景对偿付能力充足率的影响。实际压力测试需逐资产、逐负债、逐风险计量，并考虑风险间的传染效应。本案例的核心资本占比约为46,800/57,000 ≈ 82%。

1 股票价格下跌30%情景 Equity Price Down 30%

模拟股票价格大幅下跌：蓝筹股下跌30%，其他股票下跌40%。

参数：
股票资产（蓝筹）= 15,000 万  |  股票资产（其他）= 6,667 万
蓝筹股跌幅 = 30%  |  其他股票跌幅 = 40%

[1] 实际资本减少：
蓝筹股减值 = 15,000 × 30% = 4,500 万
其他股票减值 = 6,667 × 40% = 2,667 万
实际资本减少合计 = 4,500 + 2,667 = 7,167 万
实际资本情景 = 57,000 - 7,167 = 49,833 万

[2] 最低资本变化（简化）：
权益价格风险MC增加 = (4,500×0.20 + 2,667×0.30) = 1,700 万
最低资本情景 ≈ 20,081 + 1,500 = 21,581 万
（实际最低资本变化需重新聚合，此处简化）

[3] 充足率计算：
核心资本 = 49,833 × (46,800/57,000) = 49,833 × 0.821 ≈ 40,928 万
核心充足率 = 40,928 / 21,581 = 189%
综合充足率 = 49,833 / 21,581 = 231%
核心充足率：233% → 189% （-44pp） | 综合充足率：284% → 231% （-53pp）
注：股票下跌导致实际资本大幅减少7,167万，同时最低资本小幅增加。核心资本占比按82%简化计算。
2 利率下降100bp情景 Interest Rate Down 100bp

模拟利率下降100个基点。利率下降导致固收资产升值，但负债评估利率下降导致准备金增加更多，净值为负。

参数：
固收资产久期 ≈ 5年  |  负债久期 ≈ 8年

[1] 资产负债价值变化：
固收资产DV变化 = +5,000 万（资产升值）
负债DV变化 = +8,000 万（准备金增加）
净值变化 = 5,000 - 8,000 = -3,000 万
实际资本情景 = 57,000 - 3,000 = 54,000 万

[2] 最低资本变化：
利率风险MC增加 ≈ 2,000 万
最低资本情景 ≈ 20,081 + 2,000 = 22,081 万
简化取 22,000 万

[3] 充足率计算：
核心资本 = 54,000 × 0.82 = 44,280 万
核心充足率 = 44,280 / 22,000 = 201%
综合充足率 = 54,000 / 22,000 = 245%
核心充足率：233% → 201% （-32pp） | 综合充足率：284% → 245% （-39pp）
注：寿险公司负债久期通常大于资产久期，利率下降导致准备金增幅大于资产升值，实际资本减少。这是寿险公司"久期错配"的典型影响。
3 退保率翻倍情景 Surrender Rate Doubling

模拟退保率翻倍。大量退保导致准备金释放，但需支付退保金，同时可能被迫低价变卖资产，产生现金流缺口。

参数：
退保率 × 2.0  |  假设资本侵蚀 ≈ 5%（退保损失+资产变现损失）

[1] 实际资本变化（简化）：
资本侵蚀 = 57,000 × 5% = 2,850 万
实际资本情景 = 57,000 × 0.95 = 54,150 万

[2] 最低资本变化：
退保风险MC增加 ≈ 3,000 万
最低资本情景 ≈ 20,081 + 3,000 = 23,081 万
简化取 23,000 万

[3] 充足率计算：
核心资本 = 54,150 × 0.82 = 44,403 万
核心充足率 = 44,403 / 23,000 = 193%
综合充足率 = 54,150 / 23,000 = 235%
核心充足率：233% → 193% （-40pp） | 综合充足率：284% → 235% （-49pp）
注：退保率翻倍导致约5%的资本侵蚀，主要来自退保损失和资产变现损失。实际影响取决于产品退保惩罚条款和资产流动性。
4 逆周期叠加情景 Countercyclical Overlay

模拟多风险叠加：股票 -20% + 利率 -50bp + 退保 × 1.5。虽然各单项冲击幅度低于对应必测情景，但多风险叠加效应使综合冲击最为严重。

参数：
股票总资产 = 21,667 万  |  股票跌幅 = 25%（加权平均）
利率下降 = 50bp  |  退保率 × 1.5

[1] 股票减值：
股票减值 = 21,667 × 25% = 5,417 万

[2] 利率影响（净值）：
利率下降50bp净值变化 = -1,500 万
（利率下降100bp净值-3,000万，50bp约减半）

[3] 退保影响：
退保率×1.5的资本侵蚀 ≈ 2,850 万
（退保翻倍侵蚀2,850万，1.5倍约2,850万）

[4] 实际资本合计：
实际资本情景 = 57,000 - 5,417 - 1,500 - 2,850 = 47,233 万

[5] 最低资本：
最低资本情景 ≈ 23,500 万
（权益+利率+退保风险MC综合增加）

[6] 充足率计算：
核心资本 = 47,233 × 0.82 = 38,731 万
核心充足率 = 38,731 / 23,500 = 165%
综合充足率 = 47,233 / 23,500 = 201%
核心充足率：233% → 165% （-68pp） | 综合充足率：284% → 201% （-83pp）
注：逆周期叠加情景虽然各单项冲击幅度低于必测情景，但多风险叠加效应使综合充足率降幅最大（-83pp），体现了系统性风险的尾部相依特征。

结果分析

所有压力情景下，西红人寿的综合偿付能力充足率仍高于100%，核心充足率也高于100%，表明公司在极端情景下仍具备偿付能力。但逆周期叠加情景下核心充足率从233%降至165%，降幅达68个百分点（综合降幅83pp），是所有情景中冲击最大的。

资本补充触发条件

如压力情景下充足率低于100%，需启动资本补充计划，包括：① 利润留存；② 股东增资；③ 发行资本补充工具；④ 调整资产配置和业务结构。西红人寿当前基准充足率较高（284%），压力测试下仍维持充足，暂无需启动资本补充计划。但建议持续监控逆周期风险，做好资本补充预案。

情景敏感性分析

各情景的充足率降幅反映了西红人寿的风险敏感性：① 股票-30%（-53pp）——权益价格风险敏感度高，反映21,667万股票资产敞口较大；② 利率-100bp（-39pp）——久期错配导致利率敏感度为负；③ 退保翻倍（-49pp）——退保风险中等敏感；④ 逆周期叠加（-83pp）——多风险叠加效应显著，约为各单项情景之和的1.3倍，体现了尾部相依效应。建议：① 适当降低股票配置比例或增加对冲；② 缩小资产负债久期缺口；③ 优化产品退保惩罚条款。
